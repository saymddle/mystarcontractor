# My Star Contractor

Initial application scaffold for a construction management platform built with:

- Next.js App Router
- TypeScript
- Supabase client hooks

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Current routes

- `/` marketing and product overview
- `/pm` project manager dashboard stub
- `/client` client portal stub

## Environment

Create `.env.local` when you are ready to connect Supabase:

```bash
NEXT_PUBLIC_SUPABASE_URL=your-project-url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```
